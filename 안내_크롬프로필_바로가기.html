PART 3

휴대폰에도 넣어두기

출장 중이거나 교실에 있을 때 유용합니다. 선택 사항이니 안 하셔도 됩니다.

아이폰 · Safari

  1. 사파리로 온라인교무실 주소 열기
  2. 화면 아래 공유 버튼(↑ 모양) 누르기
  3. 목록을 내려서 홈 화면에 추가
  4. 이름을 온라인교무실로 → 추가

안드로이드 · Chrome

  1. 크롬으로 온라인교무실 주소 열기
  2. 오른쪽 위 ⋮ 누르기
  3. 홈 화면에 추가 누르기
  4. 이름을 온라인교무실로 → 추가

가능하지만 메뉴 이름이 다릅니다. 이 안내서대로 하시려면 크롬을 쓰시는 편이 편합니다.

이 세 개가 되면 설정은 끝난 겁니다.

  • 크롬 오른쪽 위 아이콘이 학교 계정으로 보인다
  • 바탕화면에 온라인교무실 아이콘이 있다
  • 그 아이콘을 더블클릭하면 바로 사이트가 열린다 (로그인 화면이 뜨지 않는다)
